# Poster Generator

A tool that makes custom event posters in seconds.

## The problem
The Terry Fox Foundation has marketing assets, but they're generic — every city and event needs its own poster. The usual ways to get one all hurt: AI generation makes things up, Figma needs skills most volunteers don't have, and asking the foundation's designer means waiting days.

## What it does
Five approved designs, ready to go. Pick one, edit the text for your event, and get a finished poster. Fill in one poster and the other four fill in with it. No Figma, no designer in the middle, no AI subscription, no AI slop — the design is already approved, only the text changes. Smart QR code included. Export as PNG, JPEG, or PDF.

For the few volunteers with some design skill, there's a Figma-lite editor: text, spacing, and position, all with plain-language labels in a tappable sidebar. The font can't be changed — brand rules stay locked. Most people never need it.

Sign in, save a draft, come back any time — interrupted work doesn't get lost.

Before downloading, the human reviews the poster and changes what needs changing. Nothing goes out unreviewed.

## The result
Hours of repetitive work became custom posters in seconds. Volunteers make their own posters now — no waiting days, no bottleneck.

## Bonus
The app works with an agent too: through code, an agent like Muse can fill in a poster. But the human still approves.

## How it was built
Problem definition, UX/UI, and a custom rendering engine — everything runs in the browser. I directed the build with AI agents: I set the problem, the vision, and the plan, and owned the result end to end.
